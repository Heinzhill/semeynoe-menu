СЕМЕЙНОЕ МЕНЮ — мобильное приложение (iPhone и Android)

Файлы:
  index.html  — само приложение (всё внутри: дизайн, база блюд, расчёты)
  manifest.json — название и иконка для установки на телефон
  sw.js — работа без интернета
  icons/ — иконки
  images/ — фото блюд (по желанию)

Как выложить бесплатно на GitHub Pages:
  1. Зарегистрируйтесь на github.com.
  2. «New repository» → имя, например semeynoe-menu → Public → Create.
  3. «uploading an existing file» → перетащите ВСЁ содержимое этой папки (не саму папку) → Commit changes.
  4. Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
  5. Через 1–2 минуты приложение будет по адресу https://ВАШ-ЛОГИН.github.io/semeynoe-menu/

Установка:
  iPhone: откройте адрес в Safari → «Поделиться» → «На экран Домой».
  Android: откройте в Chrome → «Установить приложение» (или ⋮ → «Добавить на главный экран»).

Как вносить изменения:
  Замените файл на GitHub (откройте файл → значок карандаша или Add file → Upload files).
  В sw.js увеличьте номер версии (menu-v1 → menu-v2). Телефон подхватит новую версию при следующем открытии
  (иногда нужно закрыть и открыть приложение дважды). Данные семьи на телефоне при этом сохраняются.
